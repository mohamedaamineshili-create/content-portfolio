# content-portfolio

Content creator portfolio of Mohamed Amine Sehili. Static site (HTML/CSS/JS), deployed on Vercel from `main`.

## Add a video
1. Put a 6-second muted preview in `assets/previews/<id>.mp4` (360×640, H.264).
2. Put a poster in `assets/thumbs/<id>.jpg` (360×640).
3. Add one line to `js/data.js`.
